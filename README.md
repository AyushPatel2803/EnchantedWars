# Enchanted Wars

[![CI](https://github.com/AyushPatel2803/EnchantedWars/actions/workflows/ci.yml/badge.svg)](https://github.com/AyushPatel2803/EnchantedWars/actions/workflows/ci.yml)

Enchanted Wars is a two-player fantasy card battle game where you place Hero cards, roll for their abilities and play Items and Spells to outsmart your opponent, online or locally against an AI.

# Client

Install dependencies
```
npm install
```

Run in development mode
```
npm run dev
```

# Server

Install dependencies
```
npm install
```

Run in development mode
```
npm run dev
```
